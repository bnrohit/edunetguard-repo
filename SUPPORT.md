# Support EduNetGuard

EduNetGuard is intended to remain **free and open source** for school IT teams and the wider community.

If EduNetGuard helps your organization monitor services, understand outages, or communicate infrastructure health more clearly, you can optionally support ongoing development.

## What community support helps fund

Contributions can help with:

- ongoing maintenance and bug fixes
- additional K-12 monitoring and reporting capabilities
- testing and compatibility work
- documentation, examples, and deployment guidance
- hosting and development infrastructure
- security hardening and dependency maintenance
- accessibility and UI improvements
- community-requested features

## Open-source pledge

Support is always optional.

- EduNetGuard remains open source under its existing license.
- Core monitoring features are not locked behind a donation.
- Donors do not receive privileged monitoring access or hidden capabilities.
- Community support is used to help sustain and improve the project.
- Community contributions are voluntary project support and are **not represented as tax-deductible charitable donations** unless the maintainer later establishes and documents an applicable charitable status.

## Stripe support

A Stripe-hosted donation checkout is being prepared so payment-card information is handled by Stripe rather than by EduNetGuard or GitHub.

**Live donation link status:** not yet published.

The connected Stripe account used during development is currently a **sandbox/test account**, so this repository intentionally does not publish that test link as if it accepted real donations. Once the maintainer enables a live-mode Stripe account, this page and GitHub funding metadata can be updated with the production Stripe donation URL.

When enabled, the intended Stripe checkout will be a **pay-what-you-want, one-time contribution** with a clear statement that support is optional and that EduNetGuard remains free and open source.

## Other ways to help

You can also support the project without donating by:

- reporting reproducible bugs
- improving documentation
- contributing monitor templates or sanitized examples
- adding tests
- sharing the project with other school IT teams
- contributing safe integrations and accessibility improvements

Thank you for helping keep practical K-12 infrastructure tools accessible to the community.
